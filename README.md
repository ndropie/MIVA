# MIVA

## A Python-based personal AI voice assistant powered by local AI, Whisper, Ollama, and Kokoro.

main.py -> entry point
app/core/miva.py -> MIVA itself
app/ai/model.py -> AI/LLM interface

### responsibilities
main.py
   |
   | starts the application
   |
app/core/miva.py
   |
   | controls MIVA's behavior
   |
app/ai/model.py
   |
   | communicates with the AI model
   |
